# Support

Lumi can be self-hosted or run for you by Nieve (see [Two ways to run Lumi](README.md#two-ways-to-run-lumi)). The community support below is for self-hosted installations and for contributors.

## Questions and installation help

Start with the [documentation](https://docs.lumi.nieve.ai): [Getting started](https://docs.lumi.nieve.ai/getting-started) for development, [Self-hosting](https://docs.lumi.nieve.ai/self-hosting) and [Operations](https://docs.lumi.nieve.ai/self-hosting/operations) for installations, and [Configuration](https://docs.lumi.nieve.ai/configuration) for setting up a business. If you are blocked, open a [GitHub issue](https://github.com/nieve-consulting/lumi/issues) with your goal, version or commit, environment, and the steps you tried.

Community support is provided as maintainer availability permits. There is no guaranteed response time or service-level agreement.

If a documentation page is wrong or missing something, open an issue or a pull request on [nieve-consulting/lumi-docs](https://github.com/nieve-consulting/lumi-docs).

## Bugs and feature requests

Use the issue templates and search existing issues first. Include a minimal reproduction and sanitized logs for bugs. For feature requests, explain the user outcome and how you would verify it.

Never post API keys, environment files, private conversations, or customer data. Report vulnerabilities privately using [SECURITY.md](SECURITY.md).

## Commercial enquiries

For Nieve's managed Lumi, see [lumi.nieve.ai](https://lumi.nieve.ai). For implementation, integrations, or deployment assistance with your own installation, contact Nieve through [Nieve’s contact page](https://www.nieveconsulting.com/contact). Terms are agreed separately with Nieve; community support through this repository stays as described above.
