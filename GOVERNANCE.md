# Governance

Lumi is maintained by Nieve Consulting. Nieve sets product direction, reviews contributions, and controls releases. This is a company-maintained project, not a foundation-governed project.

## Decisions and contributions

Use issues to propose meaningful changes and pull requests to review implementations. Maintainers consider user benefit, compatibility, security, operational cost, and ongoing maintenance. A proposal or roadmap entry is not a delivery commitment.

Maintainers make final merge and release decisions. Contributions are welcome from individuals, agencies, and companies. Submitting work does not automatically grant repository access or maintainer status. Nieve appoints maintainers based on sustained contributions and project needs.
